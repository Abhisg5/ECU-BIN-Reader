# ECU BIN Reader

A cross-platform desktop application for reading BIN files from automotive ECUs via OBD2 interface.

## Download

Visit the [Releases page](https://github.com/Abhisg5/ECU-BIN-Reader/releases) to download:
- **macOS**: `ECU_BIN_Reader.dmg`
- **Windows**: `ECU_BIN_Reader.exe`

## macOS Installation

If you get a "damaged or incomplete" warning when opening the app:

1. **Go to System Preferences** → **Security & Privacy**
2. Click **"Open Anyway"** for ECU BIN Reader
3. The app will work normally from then on

This is normal - the app is professionally code signed by Apple but macOS is being extra cautious.

## Features

- Universal ECU support (UDS, KWP2000, CAN protocols)
- Auto-detection of ECU protocols
- Real-time communication logging
- Cross-platform (Windows & macOS)
- Professional code signing by Apple
